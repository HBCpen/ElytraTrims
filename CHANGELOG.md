## Features
### Trim Randomizer
This feature allows applying any trim, including ones previously available only with 
[Elytra Trims Extensions](https://modrinth.com/mod/elytra-trims-extensions) and the corresponding mod.
The caveat is that you can only get them at random.
![all the trims](https://i.imgur.com/Wkt5nSa.jpeg)

A lot of these trims are inspired by other mods adding their own patterns,
featuring **69** trims in total:
- **Vanilla Minecraft**: Bolt, Coast, Dune, Eye, Flow, Host, Raiser, Rib, Sentry, Shaper, Silence, Snout, Spire, Tide, Vex, Ward, Wayfinder, Wild.
- **Elytra Trims exclusive**: Construction, Fly, Gems, Grate, Grid, Start, Web, Whirl.
- **[More Armor Trims](https://modrinth.com/mod/more-armor-trims)**: Beast, Fever, Greed, Horizon, Myth, Nihility, Origin, Ram, Storm, Wraith, Twilight, Witness, Parasite.
- **[Ancient Aether](https://modrinth.com/mod/ancient-aether)**: Ancient, Ascended, Mechanical, Mosaic, Mysterious, Royal, Solar, Whale, Wynd.
- **[Geode+](https://modrinth.com/mod/geode-plus)**: Celeste, Heart, Wrap.
- **[Atmospheric](https://modrinth.com/mod/atmospheric)**: Apostle, Druid, Petrified.
- **[Jaden's Nether Expansion](https://modrinth.com/mod/jadens-nether-expansion)**: Rift, Spirit, Valor.
- **[Frostiful](https://modrinth.com/mod/frostiful)**: Frosty, Snowman, Glacial.
- **[Eternal Starlight](https://modrinth.com/mod/eternal-starlight)**: Keeper, Twining.
- **[Alex's Caves](https://modrinth.com/mod/alexs-caves)**: Polarity.
- **[Caverns & Chasms](https://modrinth.com/mod/caverns-and-chasms)**: Exile.
- **[Aether: Lost Content](https://modrinth.com/mod/aether-lost-content)**: Noble.
- **[More Sniffer Flowers](https://modrinth.com/mod/more-sniffer-flowers)**: Aroma.
- **[Neapolitan](https://modrinth.com/mod/neapolitan)**: Primal.
- **[Unusual End](https://modrinth.com/mod/unusual_end)**: Ancient.
- **[Yung's Cave Biomes](https://modrinth.com/mod/yungs-cave-biomes)**: Ancient.

These trims can be obtained in one of two ways:
1. Replacing the pattern item with a trial key provides a random trim 
  that persists until someone crafts it.  
  ![option 1](https://i.imgur.com/WbL7MRG.png)
2. Replacing the pattern item with an ominous trial key provides a random trim 
  that updates every time you fill in the recipe slots.  
  ![option 2](https://i.imgur.com/8jWNiDJ.png)
